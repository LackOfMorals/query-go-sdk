# Architecture, Code & Security Review

**Date:** 2026-06-04  
**Branch:** review/architecture-code-security

## Critical

### 1. URL path doubling bug — `client.go:119` + `api.go:144`

`defaultOptions()` sets `baseURL` to `"http://localhost:7474/db/neo4j/query/v2"`, then `doAuthenticatedRequest` appends the path again:

```go
fullURL := s.baseURL + "/db/neo4j/query/v2"
// → http://localhost:7474/db/neo4j/query/v2/db/neo4j/query/v2
```

Every request using the default configuration will fail with a 404. The example in `examples/basicQuery/` works only because it explicitly calls `WithBaseURL("http://localhost:7474")`.

**Fix:** Change the default in `client.go:119`:
```go
baseURL: "http://localhost:7474",
```

### 2. `WithDatabase` accepted but silently ignored — `client.go:150-159`, `api.go:144`

The option stores the database name in config, but `doAuthenticatedRequest` hardcodes `"/db/neo4j/query/v2"`. Callers targeting a non-`neo4j` database will get silent misdirection.

**Fix (short-term):** Pass `database` through `Config` into `apiRequestService` and use it in URL construction:
```go
fullURL := fmt.Sprintf("%s/db/%s/query/v2", s.baseURL, s.database)
```
**Fix (minimal):** Remove the option and document the limitation until it is implemented.

## Major

### 3. Authorization header value logged at DEBUG — `client.go:351`

```go
slog.String("authheader", o.config.authHeader.Authorize())
```

This emits the full `Authorization` header value (the Base64-encoded Basic credentials or the raw Bearer token) into the debug log. Debug logging is routinely enabled in development and sometimes in production.

**Fix:** Remove the line entirely. If auth-type debugging is needed, log only the scheme:
```go
slog.String("authscheme", strings.SplitN(o.config.authHeader.Authorize(), " ", 2)[0])
```

### 4. `WithDefaultHeaders` does not protect the `Authorization` header — `client.go:239-242`

```go
var protectedHeaders = map[string]struct{}{
    "content-type": {},
    "user-agent":   {},
}
```

`"authorization"` is absent, so a caller can override the Authorization header via `WithDefaultHeaders`, replacing the configured credentials silently.

**Fix:**
```go
var protectedHeaders = map[string]struct{}{
    "authorization": {},
    "content-type":  {},
    "user-agent":    {},
}
```

### 5. `fmt.Sprintf("%s", bodyMarshalled)` — `query.go:52`

Non-idiomatic and allocates an extra string copy via the `fmt` machinery.

**Fix:**
```go
body := string(bodyMarshalled)
```

### 6. Stale `slog.Int("services", 6)` — `client.go:344`

Only one service (`Query`) is initialised. This is copy-paste debris from the Aura SDK.

**Fix:** `slog.Int("services", 1)` or remove the attribute.

### 7. Silent response truncation — `httpclient/types.go:13`, `httpclient.go:149`

`io.LimitReader` silently truncates at `DefaultMaxResponseSize` (10 MB). A large result set will be returned incomplete without any error, leading to data loss the caller cannot detect.

**Fix:** Detect truncation explicitly:
```go
limitedReader := io.LimitReader(resp.Body, DefaultMaxResponseSize+1)
responseBody, err := io.ReadAll(limitedReader)
if err != nil {
    return nil, fmt.Errorf("failed to read response body: %w", err)
}
if int64(len(responseBody)) > DefaultMaxResponseSize {
    return nil, fmt.Errorf("response body exceeds maximum size of %d bytes", DefaultMaxResponseSize)
}
```

## Security

### 13. HTTP allowed for arbitrary base URLs — `client.go:195-208`

The HTTPS enforcement block is commented out with `/* Might enforce this for Aura DBs */`. Over plain HTTP, Basic auth credentials are transmitted in cleartext to any server the caller points the client at.

**Recommendation:** Re-enable the HTTPS check, and provide `WithInsecureBaseURL` (already used in integration tests) as an explicit escape hatch requiring deliberate opt-in:
```go
// WithInsecureBaseURL is WithBaseURL without HTTPS enforcement.
// Use only in tests or when connecting over a trusted loopback interface.
func WithInsecureBaseURL(u string) Option { ... }
```

### 14. Debug log contains credentials — see Major #3 above.

## Positive observations

- **Transformer pattern** mirrors the Neo4j Go driver API — good ergonomics for existing driver users.
- **`decode` package** is comprehensive: typed JSON, temporal types, ISO 8601 duration, WKT Point, Node/Relationship/Path — well-engineered.
- **Retry policy** (`httpclient.go:22-33`) is conservative and correct: retries only on network errors, never on HTTP responses, respects context cancellation.
- **Connection pool** settings in `httpclient.go:64-74` are production-appropriate: `MaxIdleConnsPerHost: 20`, explicit TLS 1.2 minimum, staged timeouts.
- **Error re-export** (`type Error = api.Error`) keeps the public API clean without leaking internal packages.
- **`QueryService` interface** at the top level enables clean test doubles.
