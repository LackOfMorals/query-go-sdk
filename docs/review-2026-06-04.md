## Remaining open finding

### #13 — No HTTPS enforcement (`client.go:195-208`)

The HTTPS check remains commented out:

```go
/* Might enforce this for Aura DBs if we can figure out the URL.
if !strings.HasPrefix(baseURL, "https://") {
    return errors.New("base URL must use HTTPS to protect credentials in transit")
}
*/
```

Over plain HTTP, Basic auth credentials travel in cleartext. The recommended fix is to enable the check and provide an explicit escape hatch for local development:

```go
// WithBaseURL sets the Neo4j server base URL. Must use HTTPS.
func WithBaseURL(baseURL string) Option {
    return func(o *options) error {
        if baseURL == "" {
            return errors.New("base URL must not be empty")
        }
        if !strings.HasPrefix(baseURL, "https://") {
            return errors.New("base URL must use HTTPS to protect credentials in transit")
        }
        o.config.baseURL = baseURL
        return nil
    }
}

// WithInsecureBaseURL is WithBaseURL without HTTPS enforcement.
// Use only in tests or when connecting over a trusted loopback interface.
func WithInsecureBaseURL(baseURL string) Option {
    return func(o *options) error {
        if baseURL == "" {
            return errors.New("base URL must not be empty")
        }
        o.config.baseURL = baseURL
        return nil
    }
}
```

## New issue found during re-review (fixed in this pass)

### protectedHeaders keys were mixed case — protection was broken (`client.go`)

The fix for finding #4 added `"Authorization"` and `"Accept"` to `protectedHeaders`, but the lookup uses `strings.ToLower(k)`:

```go
if _, protected := protectedHeaders[strings.ToLower(k)]; !protected {
```

Mixed-case map keys (`"Authorization"`, `"Accept"`) never match after `ToLower`, so the protection was silently inoperative. Fixed in this pass — all keys are now lowercase and consistent:

```go
var protectedHeaders = map[string]struct{}{
    "authorization": {},
    "content-type":  {},
    "accept":        {},
    "user-agent":    {},
}
```

`"user-agent"` was also restored (it had been dropped from the original set).
